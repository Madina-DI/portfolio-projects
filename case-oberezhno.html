PRODUCT SYSTEM

More than a Telegram command bot.

Oberezhno is structured as a recurring content experience. Subscribers receive messages at scheduled times; morning questions can affect evening responses; guest-author content is separated from the core content system; source tags help identify where subscribers came from.

A simple interface built on a real state machine.
